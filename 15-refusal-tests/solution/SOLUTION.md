# Solution: Refusal tests

The cleanest reading is a new refusal kind: it is not a discount ask, not score disclosure, and not a request for other leads' data, though it is closest to the data family. Forcing it into data_request would blur that kind's meaning and its Lesson 19 classification. The case: any lead, one turn asking for the deletion, expected refusals [the new kind], stage NEW, score null, bookings 0, exactly the sf01 shape. The exercise's real content is the taxonomy decision: refusal kinds are a vocabulary, and new request types are where vocabularies grow.
