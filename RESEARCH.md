# Competitor research: learning to test and evaluate AI agents

Researched 2026-11-06 by web search, before any lesson was written. Facts below are what the sources showed on that date. Prices, tiers, and version numbers in this field move quickly, so each claim is dated, and vendor reported numbers are labelled as vendor reported. The course itself names frameworks only where a concept needs a name, keeps its runnable core on the Python standard library, and dates every framework mention in the lesson text.

## The platform courses: strong, gated, and stack bound

**DeepLearning.AI, "Evaluating and Improving Agentic Applications"** (with Arize AI, instructor Laurie Voss; the course page showed a publish date of 2026-11-04 when read on 2026-11-06). Five modules: foundations of evaluation, observing and benchmarking agent behaviour, building trustworthy evaluators (including Cohen's kappa as a measure of judge reliability), evaluating actions and outcomes, and improving agents from evaluation results. The hands-on labs run on Arize Phoenix. Access sits behind DeepLearning.AI Pro; a review dated 2026-09-28 listed Pro at $30 per month, or $25 per month billed annually. Strengths: current, structured, and it teaches evaluator validation, which most material skips. Limits for our purposes: the practice is bound to one vendor's observability platform, and the paywall puts it out of reach for the beginners this programme serves.

**Maven, "AI Evals For Engineers & PMs"** (Hamel Husain and Shreya Shankar). A live four week cohort course, listed with 17 sessions and 11 lessons; a course listing on beri.net showed a list price of $4,200, and the course page reports more than 4,500 past students (vendor reported). Its method is the field's reference workflow: error analysis on real traces first, failure taxonomies, code based evaluators before model judges, LLM judges validated against human labels (the instructors' line of work includes "Who Validates the Validators?", Shankar et al., UIST 2024), and binary pass or fail labels preferred over Likert scales. Strengths: it is the deepest treatment of evaluation as an engineering discipline. Limits: live cohort, priced for professionals, and centred on analysing production traces, which assumes the learner already runs an agent in production.

**LangChain Academy, "Introduction to Agent Observability & Evaluations"**. Free, with 43 lessons and about 7.5 hours of video (per the course page and coverage on i-programmer). It teaches datasets, evaluators, and experiments inside LangSmith; LangSmith's free tier was reported at 5,000 traces per month. Strengths: genuinely free and hands on. Limits: the skills are LangSmith skills; the concepts travel, the mechanics do not, and evaluation is framed around what the platform records.

## The primary sources the field builds on

**Anthropic, "Demystifying evals for AI agents"** (engineering blog, 2026-01-09). The vocabulary this course adopts: a task, run as trials, producing a transcript and an outcome; code based, model based, and human graders; pass@k (at least one of k trials passes) versus pass^k (all k trials pass); capability evals versus regression evals; start with 20 to 50 tasks drawn from real failures; grade the outcome and the final state rather than the transcript's claims; give every trial a clean environment. Anthropic's newer developer guidance adds an eval driven hillclimbing workflow: change one thing at a time and judge against held out examples. This course's Modules 6 and 7 and the capstone's clean environment rule come straight from this post, and Lesson 20 and Lesson 22 say so.

**Promptfoo** (open source, MIT). A CLI driven evaluation tool configured in YAML: deterministic assertions (equals, contains, regex, is-json, levenshtein and friends) alongside model graded ones (llm-rubric, factuality), plus cost and latency assertions and a red teaming mode (third party listings counted 40 to 50 or more plugins). OpenAI announced its acquisition of Promptfoo in March 2026, with the tool remaining MIT licensed and multi provider. Separately, OpenAI's hosted Evals product went read only on 2026-10-31 with shutdown scheduled for 2026-11-30, and its migration guidance points users to Promptfoo (per a migration guide read 2026-11-06). A hands on guide ran promptfoo 0.125.1 and noted a Node 22.22 or newer requirement. Lesson: deterministic assertions are a first class citizen in the tool the industry is consolidating around; this course teaches that layer directly, with no install.

**DeepEval** (Confident AI, Apache 2.0). A pytest style Python framework for LLM and agent evaluation; the metric catalogue includes G-Eval, hallucination, faithfulness, and agentic metrics such as Task Completion and Tool Correctness. PyPI showed the 3.x line (3.8.3) in November 2026. Most of its headline metrics need a judge model, which means an API key and a nondeterministic grader: a legitimate choice, and the opposite end of the spectrum from this course's deterministic first stance.

**RAGAS** (0.4.3 current as of October 2026, per DataCamp's coverage). The standard RAG metric set: faithfulness, answer relevancy, context precision, context recall, all judge based. Its API changed substantially across the 0.1, 0.2, and 0.4 lines, which is itself a lesson in why this course dates framework mentions and keeps its own retrieval boundary tests (Lesson 26) on a hand built stand-in, cross linked to Course 5, which teaches retrieval evaluation in depth.

**Braintrust** (commercial). An evaluation platform built on data, task, and scores primitives, with dataset versioning, experiments, a `bt eval` CLI, and a GitHub Action; its autoevals library is MIT licensed. It represents the platform end of the market: excellent workflow, account required.

**Mutation testing** (Wikipedia's mutation testing article and the Stryker documentation). The discipline the capstone borrows: a mutant is a small deliberate change to the system; a test suite kills a mutant when a test fails on it; the mutation score is killed mutants divided by total mutants, excluding equivalents. Established tools include mutmut for Python, Stryker, and PIT. Agent suites almost never report a mutation score; Lesson 19's error taxonomy and the capstone's eight hand built mutants exist to close that gap at teaching scale.

## The gap this course takes

Everything serious in this space is at least one of: paid (Maven at a professional price, DeepLearning.AI behind a subscription), platform bound (LangSmith, Phoenix, Braintrust), judge first (DeepEval and RAGAS headline metrics need a model API key before a beginner can run anything), or reference material rather than a runnable curriculum (the Anthropic post is the best single read in the field, and it is a blog post).

Nobody teaches deterministic first agent testing as a complete, free, offline course: one small agent you can hold in your head, tested with scenario fixtures, trajectory and state assertions, safety sets, statistical honesty about repeated runs, budgets as tests, CI gating, and a capstone graded partly by mutation testing. That is the gap. This course fills it on the Python standard library alone, in the QualBench spirit (TechAura's own benchmark project: deterministic scenarios, fixed dates, no LLM judge), testing the kinds of agents Courses 1, 3, and 5 teach you to build.
