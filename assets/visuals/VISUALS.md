# Visual guide

Every core idea in this course has a diagram. They are drawn in one
style so the shapes stay familiar: navy boxes are the main actor or
step, light boxes are supporting steps, amber boxes are gates where
a human or a safety check decides. Each diagram also lives inside
the lesson it belongs to.

| Diagram | What it teaches | Used in |
|---|---|---|
| [course-map.svg](course-map.svg) | The whole course on one page: 10 modules, one agent, one suite | README |
| [why-different.svg](why-different.svg) | The four differences: clock, state, paths, boundaries | Lesson 01 |
| [twin-pattern.svg](twin-pattern.svg) | The deterministic twin and its three rules | Lesson 03 |
| [assertion-styles.svg](assertion-styles.svg) | Outcome, structural, trajectory, exact: the coupling ladder | Lesson 06 |
| [trajectory-rules.svg](trajectory-rules.svg) | The five trajectory rules on one tool sequence | Lesson 08 |
| [safety-suites.svg](safety-suites.svg) | Refusals, injection, permissions: the three safety suites | Lessons 15 to 17 |
| [pass-rates.svg](pass-rates.svg) | pass@k against pass^k, with the measured s01 and s03 numbers | Lesson 22 |
| [capstone-flow.svg](capstone-flow.svg) | Spec and gates, build, evaluate and harden, ship | Lessons 29 to 32 |

Diagrams are generated by [generate_visuals.py](generate_visuals.py)
so the set stays consistent. Edit the script, rerun it, and commit
the SVGs it writes. Every use carries descriptive alt text, so
screen-reader learners and search engines get the same content as
sighted readers.
