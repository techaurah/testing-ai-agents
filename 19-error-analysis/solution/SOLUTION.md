# Solution: Error analysis: from red to taxonomy

The single defect table is all band class (the cases whose scores sit between the old and new lines), with clean safety, stage, trajectory, and content rows. What it reveals is attribution: in the five defect table the threshold's damage is entangled with the disclosure leak in the same replies, so you cannot tell which defect owns which case without either the classification order or a single defect run. Error analysis alternates between the two views: the combined table for fix order, single defect runs for attribution.
